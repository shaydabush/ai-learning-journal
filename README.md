## Day 1 – How LLMs work
- מודל שפה ענק.מודל שאומן על כמות עצומה של טקסט ולמד מכך איך לנחש מה לענות.ולכן הוא יכול לטעות ולתת מידע שגוי

- התקפות שונות על המודלים JAILBREAK,PROMPT INJECTION ישיר,PROMPT INJECTION עקיף,דליפת מידע,הרעלת נתונים

- שיטות הגנה מפני התקפות שונות בדרכ עי שליחת דברים קריטיים לאישור בנאדם
